AI keys & capacity

The Gemini / OpenRouter pool from gemini_keys. Key values are never read into this page.

How rotation works today

Read from the deployed process-job and ai-job-extractor code.

  • Only keys with active=true and status='active' are considered; Gemini keys are preferred over OpenRouter.
  • Among usable keys it picks the least-recently-used one.
  • A 429 blocks that key for 20 seconds (rpm_blocked_until), then the call retries on another key after a 22 s sleep, up to 4 tries.
  • A 401/403 disables the key permanently (active=false).
  • requests_today counts successes only and resets by UTC date. requests_this_minute is never written by either function, so per-minute limits are not tracked.
  • When no key is usable, process-job writes a critical row to ops_alert_events.
